# SAFE — Universal Marketplace & Reservation Platform (Algeria)

Apps:
- apps/web: Mobile-first PWA (React + Tailwind + ShadCN)
- apps/api: Node/Express API (TypeScript + Prisma/Postgres)

Docs in `docs/blueprint/` cover design, schema, API, security, integrations, and CI/CD.

## Quickstart

### Web
- cd apps/web
- bun install
- bunx vite dev

### API
- cd apps/api
- cp .env.example .env
- bun install
- bunx prisma generate
- bun run dev
